## 合成数据细节
- 1.  cpt 数据 ： 使用glm 进行润色 
- 2.   sft :           使用glm模型生成问答对，按照simple ,complex和long context 

- 3.     dpo_v3 :  使用glm模型生成问题，再生成chosen和reject 

- 4.  dpo_v4 :   使用sft阶段的问题， 使用  qwen 3 8b 生成回答，使用qwen38b 基于文档生成回答，使用glm 4.7 基于文档生成回答，三组答案，组成两个dpo数据集，分别是 dpo stage1 和 dpo_stage2   【 考虑到v3版本的答案生成，本身就不是模型自身的，reject答案下降是很自然的】


- 5 dpo_v5 :     基于v4的dpo训练失败的问题，觉得可能问题在于 dpo的数据生成问题，问答对天然的分布差异就比较大，导致模型无法定位高熵token， loss曲线不稳定，因此采用生成 reject之后，再基于reject生成chosen, 且二者应当遵循相同输出格式 




## 数据合成注意点
- 1. dpo最好确保两条答案里存在一些重叠字样，这样可以实现重要token是高熵，且帮助模型关注高熵token 
- 2. dpo的reject 数据设置，如果是非训练模型合成的，那么reject一个就不是自身分布的结果天然就会reject ，但是如果是自身合成的，那么reject自己又不一定能成功，可能reject会下降

# 方案


## 第一轮方案

cpt ： 语料润色
sft： 三种类型问题 合成
dpo : 直接使用更高模型合成高质量推理和低质量推理


## 第二轮方案


第一轮方案问题：
1. dpo 的 good 和bad 回答都是非训练模型合成的，rejected 天然就下降，应该改为自身模型合成
2. dpo的合成不够精细，一个优的回答基于语料的回答，而一个bad的回答的空间非常多 ，没有考虑精细 ，应该尽可能地




第二轮方案：

- 采用qwen3 8b 自身模型 + 语料 合成 数据  -> 数据1
- 采用  更高模型 + 语料合成数据  -> 数据2


训练方案

- sft : 数据1 + 数据2 两阶段sft
- DPO ： 数据1 做dpo， 数据2再做dpo( 用数据1 作为rejected)
